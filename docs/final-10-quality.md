# Final 10% Quality Pass

Run one bounded pass after functional completion. Stop after the listed issues
are fixed or explicitly deferred with a reason.

Review spacing, alignment, typography, SF Symbols, iconography, copy, loading,
empty and error states, safe areas, orientation, light/dark appearance,
Dynamic Type, VoiceOver, Voice Control, Reduce Motion, Reduce Transparency,
Increase Contrast, transitions, gesture thresholds, sound levels, haptics,
energy, memory, and responsiveness.

Evidence must state whether each result is `SIMULATOR_VERIFIED`,
`DEVICE_VERIFIED`, or `EMPIRICALLY_VERIFIED`. Simulator evidence is necessary;
it is not device or user evidence.
