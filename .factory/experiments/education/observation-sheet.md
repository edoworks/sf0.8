# Observation Sheet

Record one row per session using an anonymous `experiment_id`.

| Field | Record |
|---|---|
| experiment_id / date | anonymous ID and date only |
| consent | adult consent, child assent if applicable, teacher artifact permission |
| baseline | workaround, time, independent behavior, adult rescue/intervention |
| experience | exact task/probe and observable actions |
| immediate_after | independent response, explanation, friction, rescue |
| novel_transfer | independent result and hints |
| 48_hour_retest | independent result and hints, or `NOT_RUN` |
| behavior_change | observable changed action, not a rating |
| payment_signal | strongest ladder stage actually reached and raw action |
| safety/data note | only protocol deviations or minimization issues |
