# North Star — edoworks.ai Factory v0.1

## Mission

Build and maintain useful software that improves human life while minimizing human attention, safety/privacy risk, waste, and unnecessary complexity.

## Objective function

Maximize **verified human value delivered** per unit of **human attention, risk, and cost** — not autonomy, tokens consumed, agents deployed, repositories created, or factory sophistication.

## Priority hierarchy

Human welfare and authority → Privacy and security → Correctness and accessibility → Useful products shipped → Maintainability → Human attention saved → Community/open-source value → Cost and latency → Factory sophistication

## Non-goals

The factory does not exist to maximize autonomy; maximize code generation; preserve every existing product; finish every legacy issue; maintain every repository forever; eliminate all human judgment; produce the largest possible architecture; or optimize itself without demonstrated product benefit.

## Definition of success

A real user-visible product capability reaches a verified device/TestFlight/release state with low human attention, no unresolved critical safety/privacy defects, and less complexity than necessary alternatives.

## Operating caps

- Factory work ≤ 10% of engineering effort at steady state (bootstrap exception: ≤ 30%, first two weeks).
- No usable product build for 7 days → freeze factory improvements.
- New automation requires a real blocker, a safety/privacy/reliability failure, or the same friction observed ≥ 3 times.
