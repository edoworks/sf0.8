# Customer-Zero Self Pass

This is a feasibility instrument for the founder's software-engineer role. It
is not population evidence, a product prototype, or an educational-effectiveness
claim.

## Rules

- Use only non-confidential code or synthetic examples.
- Keep each session to 10 minutes.
- Do not consult AI during independent sections.
- Record observations immediately; do not reconstruct them from memory.
- Alternate the predeclared control and intervention conditions.
- Stop if the task becomes an employment, privacy, security, or production-risk
  concern.

## Two conditions

### Control

Use the normal current method for the selected topic: AI, documentation,
practice site, notes, or no practice. Record what was used and whether the
answer was independently checked.

### Intervention

1. Recall the concept without AI.
2. State a prediction and confidence from 0 to 100.
3. Attempt a small unfamiliar task.
4. Inspect one plausible AI answer containing one controlled defect.
5. Identify, verify, repair, and explain the defect.
6. Schedule the next retest.

## Transfer checks

Run an AI-free transfer check after sessions 5 and 10. Use novel but
isomorphic tasks. Record:

- independent correctness;
- explanation quality;
- confidence before seeing the answer;
- analogous-error detection;
- whether the skill was useful in real code review or interview preparation;
- what current alternative would otherwise have been used.

## Decision record

- Did the intervention produce a visible advantage over control?
- Did it improve independent performance, or only assisted output?
- Did the controlled-defect task measure reasoning or merely defect pattern
  recognition?
- Did the founder return without a reminder?
- Would the founder request another session?
- Would the founder pay, deposit, refer, or schedule a follow-up?
- What should be killed or changed before any external participant is invited?

## Parent-side note

The father track is recorded separately. First capture one adult parent workflow:
the recent trigger, current workaround, time, uncertainty, and decision. Do not
use a child as an efficacy subject in this self pass and do not record child
identity or media.
