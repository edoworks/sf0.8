# Validate Internal Shovel Recurrence

## Goal

Test whether reuse discovery, bounded idle-work dispatch, proportional reuse
gating, or evidence-backed CI status recur in a second genuine Foculoom
workflow before considering broader internal sharing.

## Acceptance Criteria

- Select one candidate and one existing independent local consumer.
- Record observed recurrence, time/cost impact, workaround, and evidence
  provenance in the ledger.
- Search the canonical reuse registry before extending machinery.
- Keep the candidate `INTERNAL_INFRASTRUCTURE` unless independent external and
  economic evidence exists.
- Record a falsification or stop result if recurrence is not demonstrated.

## Stop Condition

Stop if no second consumer exists, the problem is one-off, or maintenance cost
exceeds saved human attention. Do not publish or recruit users in this issue.

## Verification

Run the ledger scanner, reuse-registry validator, and relevant local tests.
