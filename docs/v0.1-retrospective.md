## What earned permanence (v0.2 candidates, by evidence)

- **`scripts/ci-status.sh`** — born from a self-inflicted stuck-session; has already paid for itself twice.
- **The 5-Whys-on-incident discipline** — INC-2026-09-13 (mic crash) and the CI-watch failure both produced recurrence guards with teeth.
- **`scripts/check_policy.sh` inside verify.sh** — after unit-tests-can't-reach-sources broke twice, the script-level control is the honest home for source-shape gates.

## What stays rejected (no v0.2 candidacy)

Learned routing/budgets (no signal); vector DB / knowledge graph (no evidence); workspace MCP server; web dashboard; publication automation; cross-agent transcript normalization.

## Honest gaps (owner actions)

- **Branch protection** on private repos requires GitHub Pro — deferred to publication time.
- **Cold-machine recovery assumes `gh auth`** — ssh keys for `hellofoculoom` not yet configured.
- **Backup is local-only** until an off-device copy of `~/factory-backups` exists.
- **AC-8 needs owner-sourced CC0/CC BY clips.**
- **Second-agent handoff proof deferred.** v0.1 ran one route.

## What v0.2 must earn, if anything

By the factory-change gate (`measurable_expected_benefit` + `simpler_alternative_considered` + proof it blocks current product delivery): any v0.2 capability earns itself with product pain or it's rejected. The retrospective does not invent v0.2 scope. The next product session should be product work, not factory work.

## Decision

Factory v0.1 is declared provisionally complete. Verdict on the five proofs above stands. Whether the factory earned its rent recurs as a real question at the next planning point, with this document as the measured baseline.
